Fetch history

Downloads past trading sessions from ShareSansar's price page for the dates you choose, newest first, one request every seconds so it stays gentle on the site. Sessions already stored are kept and not requested again; weekends, listed holidays and dates already found to have no session are skipped. You can stop at any time and start again later: it continues with the dates still missing.
